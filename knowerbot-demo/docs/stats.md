# 트레이딩 짐 — 스탯 정리

두 시스템이 서로 다른 걸 측정함: **사전조사**는 자기보고 성향(선언적, 1회성), **모의투자 스탯**은 실제 행동(AI 채점, 세션마다 누적). 이름도 겹치지 않고 별도 스키마로 관리됨.

## 1. 사전조사 결과 (온보딩, `InvestorProfile`)

유저당 1행. 재진단하면 덮어씀(이력 없음). 설문 문항 점수를 룰 기반으로 합산해 3개 축으로 분류. 설명 문구(`explanationText`)만 AI가 생성하고, 채점 자체는 룰 기반.

| 축 | 점수 | 카테고리 라벨 |
|---|---|---|
| 리스크 성향 | `riskTotalScore` /20 | `STABLE`(안정형) / `NEUTRAL`(중립형) / `AGGRESSIVE`(공격형) |
| 투자 지식 | `knowledgeTotalScore` /12 | `BEGINNER`(초급) / `INTERMEDIATE`(중급) / `ADVANCED`(고급) |
| 정보 습관 | `infoHabitTotalScore` /8 | `INDEPENDENT`(독립형) / `MIXED`(균형형) / `DEPENDENT`(의존형) |

`/my` → "사전조사 결과" 탭에서 확인.

### 채점 방식

채팅으로 자유롭게 답하면 AI(`ConversationAnalyzer`)가 그 답이 옵션 1~4 중 뭐에 제일 가까운지 판단해서 점수를 매김(점수 자체는 룰 기반 합산, AI는 "어떤 옵션에 해당하는지"만 판단).

#### 리스크 성향 축 (5문항 × 1~4점 = 5~20점)

| 질문 | 1점 | 4점 |
|---|---|---|
| 투자 목적 | 원금 보전 최우선 | 고수익 노리고 적극 투자 |
| 손실 반응(-10%) | 바로 손절 | 손실 감수하고 더 공격적으로 |
| 수익 vs 리스크 선호 | 낮아도 안정적 수익 | 리스크 클수록 끌림 |
| 투자 기간 | 1년 이내에 쓸 돈 | 5년 이상 장기 |
| 신용거래(레버리지) 태도 | 절대 안 쓸 것 같음 | 기회되면 적극 활용 |

→ ≤10점 안정형 / ≤15점 중립형 / 16점+ 공격형

#### 투자 지식 축 (3문항 × 1~4점 = 3~12점)

| 질문 | 1점 | 4점 |
|---|---|---|
| 투자 경험(자기신고) | 전혀 없음 | 3년+ 여러 사이클 경험 |
| 개념 이해도(직접 확인) | 주식이 뭔지만 앎 | 반대매매·PER·PBR까지 이해 |
| 반대매매 이해도 | 잘 모름 | 담보비율 미달→강제청산까지 이해 |

→ ≤5점 초급 / ≤9점 중급 / 10점+ 고급

경험(자기신고, `EXPERIENCE_LEVEL`)과 실제 개념 이해도(`KNOWLEDGE_CHECK`)를 따로 물어봐서, "경험은 있다고 하는데 실제로는 잘 모르는" 유형도 잡아낼 수 있게 설계됨.

#### 정보 습관 축 (2문항 × 1~4점 = 2~8점)

점수가 높을수록 SNS·리딩방 같은 미검증 정보에 더 의존한다는 뜻 — 트레이딩 짐이 원래 겨냥하는 위험 신호.

| 질문 | 1점 | 4점 |
|---|---|---|
| 정보 출처 | 공시·재무제표 직접 확인 | SNS·리딩방 정보 많이 봄 |
| 추천 검증 습관 | 직접 재무정보부터 찾아봄 | 믿을만한 사람이면 바로 따라 삼 |

→ ≤3점 독립형 / ≤6점 균형형 / 7점+ 의존형

## 2. 모의투자 스탯 (`session_stats`)

세션마다 반복 생성, 세션당 8행. 세션 완료 시점에 AI가 턴별 매매 + 매매 이유(`reasonText`) 전체를 읽고 0~100점으로 채점해 영구 저장.

| stat_key | 라벨 | 뜻 |
|---|---|---|
| `JUDGMENT_ACCURACY` | 판단 정확도 | 매매 판단이 상황에 맞았는지 |
| `DISCLOSURE_CHECK_RATE` | 공시 확인율 | 매수 전 공시를 확인한 비율 |
| `RISK_MANAGEMENT_SCORE` | 리스크 관리 | 레버리지·반대매매 위험 관리 수준 |
| `IMPULSIVE_TRADING` | 충동매매 억제 | 근거 없이 급하게 매매하지 않는 정도 |
| `LOSS_AVERSION` | 손실 회피 대응 | 손실 상황에서 감정적으로 안 버티는 정도 |
| `CONFIRMATION_BIAS` | 확증편향 억제 | 보고 싶은 정보만 보지 않는 정도 |
| `DIVERSIFICATION` | 분산투자 | 한 종목에 몰빵 안 하는 정도 |
| `GAMBLING_SIGNAL` | 도박성 신호 낮음 | 손실 후 베팅 안 키우는 정도 |

`GET /api/simulation/{sessionId}/stats`로 세션별 조회.

## 3. 종합(집계) 스탯

`GET /api/users/me/aggregate-stats`(`AggregateStatService`)가 유저의 모든 세션 `session_stats`를 stat_key별로 평균 냄 — 별도 캐시 테이블 없이 매 요청마다 라이브로 계산. 세션이 하나도 없으면 빈 배열.

- 대시보드 tier-card: 3개만 골라 표시(판단 정확도 / 공시 확인율 / 리스크 관리), 세션 없으면 mock 값으로 폴백
- `/my` → "스탯" 탭: 8개 전부 표시, 세션 없으면 "스파링 시작하러 가기" 안내

## 향후 추천 로직 연계 (설계만 확정, 미구현)

완료 세션 0개 → 사전조사 약점 기준으로 추천, 1개 이상 → 모의투자 스탯 기준으로 추천. 두 시스템을 블렌딩(평균)하지 않고 세션 수 기준으로 컷오버 — 사전조사는 오래될수록 실제 행동과 어긋날 수 있어서, 실전 데이터가 쌓이면 그쪽을 우선함.
